# 02 — 组级逃标（逃组模型）

**What to build:** 逃标从天级细化到组级：每个计划组三态——未练 / 打卡 / 逃。通知「逃了」= 把当前组（直接打卡指针指向的组）标为逃组并结束会话；清单内组行可手动标逃/取消（力竭跳组：逃第 3 组后继续练第 4 组）；逃掉的组被直接打卡即转为打卡；直接打卡推进规则改为「第一个既未打卡也未逃的组」；动作完成判定不变（全部组打卡）；主页整日逃课卡片与反悔流移除、今日清单常驻。历史天级逃课数据迁移为组级逃标。

**Blocked by:** None — can start immediately.
